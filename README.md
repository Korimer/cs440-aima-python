This is the modified repository for all of our work with the AIMA repository for CS440.

All relevant work for a lab should be present within the SUBMISSIONS/Lab # directory. For example, our work for lab 1 can be found in [./SUBMISSIONS/Lab 1/](./SUBMISSIONS/Lab 1/).

Each Lab # folder should additionally come with a `bootstrap.ipynb` file and a `requirements.txt`. `bootstrap.ipynb` should not require any manual inspection, existing instead to be used by other ipynb files. `requirements.txt` contains a list of the required packages to run all other .ipynb files found in that lab's directory.

If an assignment dictates that a video submission is necessary, said video will also be found in that lab directory.
